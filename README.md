## 📌 Visão Geral

Esta Landing Page foi construída como parte do front-end do projeto **NetSentinel (Sistema Gerencial de Inventário e Patch Management)**.

A ferramenta visa resolver o gargalo operacional de empresas que não conhecem o estado real de seus ativos de TI, traduzindo dados técnicos complexos de vulnerabilidades (CVEs) em um Dashboard visualmente intuitivo.

O projeto está estritamente alinhado ao **ODS 16 da ONU (Paz, Justiça e Instituições Eficazes)**, promovendo a transparência institucional e a proteção contra vazamento de dados sensíveis.

***

## ✨ Principais Destaques (UI/UX)

O design foi guiado por princípios de **Interação Humano-Computador (IHC)** para reduzir a carga cognitiva dos usuários:

- **🎨 Design Semafórico:** Cores baseadas na pontuação CVSS — 🔴 Crítico · 🟡 Alerta · 🟢 Seguro · ⚫ Offline
- **📱 Responsividade (Mobile-First):** Experiência fluida em qualquer dispositivo, de celulares a monitores corporativos
- **🔡 Tipografia Focada em Dados:** Fontes `IBM Plex Sans` e `IBM Plex Mono` para alta legibilidade de indicadores técnicos
- **🌙 Dark Mode Corporativo:** Suporte a modo claro/escuro com preto neutro (sem tons azuis) para máximo contraste

## 🚀 Como Executar Localmente

**1. Clone o repositório:**
```bash
git clone https://github.com/fzaniniii/netsentinel-landing.git
```

**2. Acesse o diretório do projeto:**
```bash
cd netsentinel-landing
```

**3. Instale as dependências:**
```bash
npm install
```

**4. Inicie o servidor de desenvolvimento:**
```bash
npm run dev
```

**5. Acesse no navegador:**

Abra [http://localhost:3000](http://localhost:3000) para ver o resultado.
